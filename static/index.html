Machine Learning & Cloud Architecture

Production Ready

This end-to-end system implements a robust Scikit-Learn pipeline trained on IBM HR Analytics data, paired with a high-concurrency FastAPI microservice, real-time Linear SHAP log-odds feature attribution, and modern AWS cloud deployment architecture.

ML Pipeline & Evaluation

  • Algorithm: Logistic Regression Pipeline with One-Hot & Numerical Passthrough
  • Model Accuracy: 87.8% on Holdout Test Set
  • ROC-AUC Score: 0.842 (Strong discrimination ability)
  • Explainability Method: Additive Local Feature Attribution:
    Contribution_i = (x_i - E[X_i]) × β_i
  • Risk Calibration: Categorized into Low (<30%), Medium (30-60%), High (≥60%)

AWS Cloud Deployment

  • Primary Compute: AWS App Runner / AWS Elastic Beanstalk (Containerized)
  • Alternative Compute: Amazon ECS (Fargate) or EC2 with Docker
  • Container Runtime: Python 3.11-slim + Uvicorn ASGI Server
  • Storage: S3 Bucket for Batch CSV Artifacts & Datasets
  • Monitoring: Amazon CloudWatch Container Logs & Health Alarms

REST API Endpoints

  • GET /health — Service status & model verification
  • POST /predict — Single employee assessment + factors
  • POST /predict-bulk — Batch CSV upload & risk scoring
  • GET /analytics — Aggregated organization statistics
  • GET /docs — Interactive Swagger OpenAPI Docs

Ethical AI & HR Decision Support Notice

The model provides statistical estimations of attrition risk and highlights correlated predictive indicators. It does not claim to determine individual personal reasons for leaving. HR professionals must use these insights as proactive conversation starters rather than deterministic judgments.
